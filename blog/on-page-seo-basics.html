On-Page SEO Basics Every Small Business Should Know

July 2026 · Sohaib Younas

On-page SEO means the changes you make directly on your website to help it rank better on Google. None of it requires technical skill, just attention to a few specific elements on every page.

Page titles matter more than people think

Each page needs a unique title tag, ideally under 60 characters, that includes the main keyword a visitor would search for. "Home" is not a title. "Web Design Services in Sargodha, Pakistan" tells both Google and the visitor exactly what the page offers.

Meta descriptions win the click

The meta description is the short text shown under your title in search results. Google usually shows around 155 characters before cutting it off. Write it like a short pitch, mention the core benefit, and keep it within that limit so nothing important gets truncated.

Use one H1 per page, then structure the rest

Every page should have exactly one H1, usually matching the main topic of that page. After that, use H2 for major sections and H3 for subsections. This is not just for readability, search engines use this structure to understand what the page is actually about.

Image alt text is not optional

Alt text describes an image for screen readers and for Google's image search. Instead of "image1.jpg" or leaving it blank, write a short, accurate description like "WooCommerce supplements store homepage design." This also helps if the image fails to load.

Internal linking keeps visitors and Google moving

Link related pages to each other. A blog post about SEO basics should link to your services page. A services page should link to relevant case studies. This helps visitors find more of your work and helps Google understand which pages on your site are most important.

Page speed is part of SEO, not separate from it

Large uncompressed images and unnecessary scripts slow pages down. Google factors loading speed into ranking, especially on mobile. Compressing images and only loading heavy libraries you actually use is a real ranking factor, not just a technical nice-to-have.

The short version

Unique titles, tight meta descriptions, one H1 per page, descriptive alt text, sensible internal links, and fast loading. These six habits cover most of what on-page SEO actually is.
